# Foohi · AION 2 汉化工具

**v2.0.1** · Windows 64 位桌面程序 · 日本語入口的简体／繁体中文。

Foohi 负责程序实现与维护。界面、安装、还原和更新检查以 C# 重新实现，运行时使用 Windows 自带的 .NET Framework 4.5 及以上版本。

[下载正式版](https://github.com/Foohi666/Aion2-CN-Foohi/releases/latest) · [更新记录](CHANGELOG.md) · [数据来源](SOURCES.md)

## 使用

1. 下载 ZIP，完整解压到一个独立目录，运行 `Foohi.Aion2.exe`。
2. 完全退出游戏。程序打开后自动查找一次 Steam 与 NC／PURPLE 游戏目录；多个结果可从目录下拉框选择。未找到时，手动选择包含 `Aion2` 文件夹的游戏根目录。
3. 选择简体或繁体，点击“安装汉化”。进入游戏后将文字语言设为 **日本語**；语音按自己的偏好选择。
4. 更换简繁或恢复原版前先退出游戏。点击“还原原版”同时恢复日文资源和字体；“更多”提供旧版英文、韩文还原。

### 客户端匹配

本版资源基线为 Steam build **26429009**。安装会逐个核对四份日文资源和字体资源，全部匹配后才写入。NC／PURPLE 匹配同一资源基线时允许安装；文件不一致时会显示具体路径并停止。自动查找读取 Steam 库、Windows 安装记录及常见安装位置；没有记录的自定义路径可能需要手动选择。

NC／PURPLE 的上述判定通过离线夹具验证，尚未完成对应启动器的游戏内实测。启动器名称或旧版曾支持某客户端，不能代替当前文件匹配。游戏更新后若资源不匹配，请先确认客户端完整，并等待对应汉化数据更新。

### 备份与升级

继续兼容 1.2.1.9／1.2.1.10／2.0.0 的备份，无需删除或重新制作；资源与备份均匹配时可以直接升级：

`游戏目录/Aion2_Text_Backup/ja-JP/PackedFontAlias`

里面保存日文四份资源和字体原件，以及校验记录。请保留整个目录，不能按文件日期判断是否可删除。旧版外置日文表会原样归档到其中的 `ExternalText`，扩展名为 `.dat.bak`；失败时回滚到操作前状态。恢复原版后，已归档外置表继续保留，不重新启用旧汉化。

原件缺失时，只能使用与当前适配清单逐项匹配的备份。旧版本资源不能覆盖新版；必要时先通过启动器修复游戏文件。

## 数据与验证

本版包含 153,419 条文本，在 v2.0.0 数据上修订 236 条称号、道具、技能和界面文本，配套字体保持不变。程序实现与译文来源分开记录，详情见 [SOURCES.md](SOURCES.md)。

字体使用字符映射显示中文，内部文本与屏幕字形可能不同。复制、中文搜索及包含相关字符的玩家昵称或聊天可能受影响；这些行为尚未逐项游戏内验证。需要原版文字行为时请还原。

此前数据在 Steam 客户端已完成菜单、能力页面、背包、任务、重启及语言切换抽查。v2.0.1 完成全表离线检查、旧版升级、备份核验和五文件还原测试，并验证上一份测试包的简繁升级与还原。用户确认称号界面的“能力列表”“全部能力”显示正常；其他修订未逐项游戏内实测，NC／PURPLE 仍未单独确认游戏内验证结果。

“检查更新”读取本仓库正式 Release，展示更新内容；只有点击“确定”才打开下载页，不自动安装。

## 从源码构建

在 Windows PowerShell 5.1 或更新版本运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\Build-Release.ps1
```

产物位于 `dist`，包含 EXE、必要数据、来源说明和对应版本日志。构建使用系统 .NET Framework 编译器，无需安装额外 SDK。公开源代码位于 `src`；旧版发布及历史提交保留供追溯。
