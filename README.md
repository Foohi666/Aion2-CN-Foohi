## 功能

- **英文、日文、韩文三种文字语言入口**均可替换为简体或繁体中文，共六份专用文字表。语音使用游戏原有设置。
- **修复游戏内切换语言、切回后汉化丢失的问题**：原文件备份使用 `.bak` 扩展名，避免游戏重新扫描并加载原版备份。三种入口使用相同处理逻辑。
- 每种语言独立安装和还原，保留原文件及校验记录；还原日文不会移除英文或韩文汉化。
- 更新备份前核对新版原文件哈希，保留旧备份历史；缺少新版原文件时停止，防止旧资源覆盖新版本。
- **检查更新**读取本仓库的最新正式 Release，显示版本号与更新内容。发现新版本后，点击“确定”才会打开本仓库对应版本的下载页；点击“取消”不跳转。

## 使用

1. 从 [Releases](https://github.com/Foohi666/Aion2-CN-Foohi/releases) 下载 ZIP 并完整解压；源码下载包也包含运行所需脚本和文字数据。
2. 完全退出游戏，双击 `启动汉化工具.bat`。
3. 选择客户端及要替换的文字语言：英文、日文或韩文。
4. 阅读界面声明后，选择“简体中文”或“繁体中文”。
5. 游戏内文字语言设为对应的 `English`、`日本語` 或 `한국어`。其他未汉化语言仍显示原文；切回已汉化入口使用中文。
6. 要还原时，退出游戏并选择对应入口，点击“还原【英文/日文/韩文】”。要全部还原，请分别还原安装过的入口。

备份位于游戏目录的 `Aion2_Text_Backup/语言代码`；升级归档位于 `Aion2_Text_Backup/History`，请保留。不要把备份改回 `.pak` 等可加载扩展名。

游戏更新前建议先还原已安装入口。已更新客户端可以使用对应新版汉化包；若工具提示缺少新版原文件，请先通过 Steam 验证游戏文件。不同 Steam build 的数据不会强行套用。PURPLE 路径识别沿用原项目，但本版验证对象是上述 Steam build。

## 更新与发布

每次版本变更均记录在 [CHANGELOG.md](CHANGELOG.md)，GitHub Release 正文同步该版本记录，供界面的“检查更新”展示。

维护者修改 `version.json` 并补齐对应的更新日志后运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/Build-Release.ps1
```

脚本核验版本、更新日志和六份数据哈希，生成 ZIP、SHA256 校验文件及该版 Release 正文。构建不会自动发布或修改游戏文件。
